# Constitution Waivers

Use this file to record temporary, time-bound exceptions to constitution principles.

## Format
```
## WAIVER: <ID>
Principle: <Principle Name>
Scope: <files / modules>
Rationale: <why needed>
Risk: <impact if prolonged>
Mitigations: <steps to reduce risk>
Expires: YYYY-MM-DD (mandatory)
Owner: <name/alias>
Status: ACTIVE|EXPIRED|REVOKED
```

## Trust Gate CI Enforcement

- CI pipelines MUST invoke `scripts/ci/run_trust_gates.ps1` with default parameters. The script fails the job when any gate returns `fail` without an approved waiver.
- Waiver requests referencing trust gate results should cite the gate correlation ID and attach the signed report emitted under `artifacts/trust_gates/reports/<run_id>/`.
- Temporary bypasses must add entries to this file under a new `WAIVER:` section with `Scope: trust_gate.ci` and include the report signature hash recorded in the manifest (`trust_gate_signature`).
- Runtime SLA exemptions additionally require attaching:
	- The benchmark payload generated by `scripts/bench/perf_run.py` (`zz_artifacts/perf_latest.json`) showing `trust_suite.total.mean_ms` and the baseline reference extracted from `artifacts/perf_baseline.json` (note the multiplier in the waiver rationale).
	- The Prometheus snapshot emitted by `scripts/ci/run_perf_gates.py` (`zz_artifacts/trust_gate_metrics.prom`) so dashboards reflect the exemption window.
- Waivers expire automatically after the date recorded; extensions require governance review and re-signoff from the Quality Council.

## Retention Policy Waivers

- The default retention policy (`configs/retention/policy.yaml`) marks pins as waiver-protected. All CLI pin operations (`poetry run alphaforge-brain retention pin ...`) must cite an active waiver ID when `waiver_required: true`.
- Log each waiver-backed pin in this document with the associated run hashes, expiry date, and breach reference from `zz_artifacts/retention_breaches.log`.
- When a retention breach is logged, update the corresponding waiver entry and attach the CLI audit record emitted to `GOVERNANCE_AUDIT_PATH`.
